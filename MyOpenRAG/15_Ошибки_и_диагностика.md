# Ошибки и диагностика

## 1. Что это

Типичные сбои при развёртывании и работе OpenRAG и способы их выявления: права доступа, кодировки, таймауты инжеста, ошибки эмбеддингов и OpenSearch.

## 2. Зачем используется

Быстрая локализация причин сбоев и проверка здоровья компонентов (Docling, OpenSearch, провайдеры LLM/embedding).

## 3. Как работает

### Permission errors

- **OpenSearch**: отказ в доступе при запросе с JWT пользователя — проверка OIDC, ролей и прав в OpenSearch (backend_roles, user attribute фильтры). В логах: "access denied", AuthenticationException.
- **Файлы**: запись во временную директорию (tempfile) — права на каталог ОС; при работе в контейнере — user/group (OPENRAG_UID, OPENRAG_GID). Ошибки при сохранении загруженного файла в router (upload_ingest) могут быть из-за прав на temp.
- **Langflow**: 401/403 при вызове run или upload — неверный или просроченный LANGFLOW_KEY; проверка LANGFLOW_SUPERUSER_PASSWORD и повторная генерация ключа (get_langflow_api_key force_regenerate).

### Encoding errors

- Имена файлов с не-ASCII (кириллица и др.): нормализация через make_safe_storage_filename для ключа в индексе (filename) и для проверки дубликатов. Если заголовок HTTP с оригинальным именем содержит не-ASCII, Langflow global var ORIGINAL_FILENAME может не передаваться (в langflow_file_service проверка ord(c) < 128). Ошибки: UnicodeEncodeError при установке заголовков; несовпадение имени при удалении по имени — использовать safe_storage_filename везде, где обращаемся к OpenSearch по filename.

### Ingestion errors

- **Таймаут**: IngestionTimeoutError — увеличение INGESTION_TIMEOUT и LANGFLOW_TIMEOUT; для больших PDF возможно увеличение read timeout в clients.langflow_request.
- **Docling**: DoclingServeError — недоступность DOCLING_SERVE_URL (сеть, контейнер не запущен); таймаут конвертации; проверка /docling/health.
- **Langflow run failed**: разбор detail в ответе (message); типично — ошибка внутри flow (Docling, эмбеддинг, OpenSearch). Логи Backend и Langflow (LANGFLOW_LOG_LEVEL=DEBUG).
- **Дубликаты**: при replace_duplicates=false загрузка файла с тем же именем (после нормализации) завершится FAILED с сообщением "File with name '...' already exists".

### Embedding errors

- Неверная размерность: при смене модели эмбеддингов должно быть вызвано ensure_embedding_field_exists для нового поля chunk_embedding_*; иначе возможна ошибка маппинга или записи. Неизвестная модель — используется VECTOR_DIM по умолчанию (get_embedding_dimensions); для Ollama обязателен endpoint для probing.
- Провайдер: отсутствие API key или недоступность эндпоинта (OpenAI, Watsonx, Ollama) — ошибки внутри Langflow при выполнении компонента эмбеддингов. Проверка /provider/health.

### OpenSearch errors

- Индекс не создан: при первом запросе Backend создаёт индекс при старте (main.py); при сбое создания — проверить права и наличие OPENSEARCH_PASSWORD, доступность хоста/порта.
- Поиск по несуществующему полю: при смене embedding_model поле chunk_embedding_{model} должно существовать в маппинге; ensure_embedding_field_exists при настройке индекса/модели.

## 4. Где используется в системе

- Логи: utils/logging_config; логирование в router, task_service, langflow_file_service, processors, search_service.
- Эндпоинты диагностики: api/provider_health (check_provider_health), api/docling (health). GET /tasks/{task_id} — просмотр error в FileTask.
- Нормализация имён: utils/file_utils make_safe_storage_filename; api/documents check_filename_exists, delete_documents_by_filename_core используют safe name.

## 5. Связанные компоненты

Logging, provider_health, docling health, TaskService (error в FileTask), file_utils, embedding_fields, opensearch_queries.
