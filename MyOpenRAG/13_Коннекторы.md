# Коннекторы

## 1. Что это

Коннекторы — интеграции с внешними хранилищами документов (Google Drive, OneDrive, SharePoint). Пользователь авторизуется через OAuth, Backend сохраняет соединение (connection_id, токены); при синхронизации файлы скачиваются и обрабатываются через тот же Langflow ingestion pipeline, что и локальные загрузки, с метаданными connector_type и document_id.

## 2. Зачем используется

- Импорт документов из облака без ручной загрузки.
- Периодическая или по требованию синхронизация (sync); возможность выбора файлов/папок (в зависимости от API коннектора).

## 3. Как работает

### Local files

- Загрузка через UI (файл/папка) идёт в роут upload_ingest → TaskService → LangflowFileProcessor. Локальные пути — временные файлы на диске Backend. Коннектор «локальные файлы» не выделен отдельным коннектором; это основной сценарий Add Knowledge.

### Google Drive

- Коннектор в connectors/google_drive: OAuth (oauth.py), получение списка файлов и контента (connector.py). Тип connector_type: google_drive. При sync Backend получает список файлов (с учётом существующих в базе по document_id или filename), для каждого создаётся задача или вызывается LangflowConnectorService.sync_specific_files / sync_connector_files. Документы обрабатываются process_connector_document (временный файл → Langflow ingestion) и индексируются с owner, connector_type, document_id.

### OneDrive

- Аналогично: connectors/onedrive (oauth, connector). Тип: onedrive. Токены и список файлов хранятся через ConnectionManager.

### SharePoint

- connectors/sharepoint. Тип: sharepoint. Та же схема: OAuth, список файлов, скачивание, передача в Langflow ingestion.

### Возможные расширения

- Добавление нового коннектора: реализация BaseConnector (connectors/base.py), ConnectorDocument; регистрация в ConnectionManager; OAuth-эндпоинты и callback; вызов sync через ConnectorService/LangflowConnectorService. API коннекторов универсален: /connectors/{connector_type}/sync, status, token, disconnect, webhook.

## 4. Где используется в системе

- api/connectors.py — list_connectors, connector_sync, sync_all_connectors, connector_status, connector_token, connector_disconnect, connector_webhook.
- connectors/service.py — ConnectorService, process_connector_document (через DocumentService или прямой вызов).
- connectors/langflow_connector_service.py — LangflowConnectorService, sync_connector_files, sync_specific_files, process_connector_document (загрузка в Langflow, run flow, удаление файла из Langflow после инжеста).
- connectors/connection_manager.py — хранение и загрузка соединений.
- connectors/google_drive, onedrive, sharepoint — реализации коннекторов.

## 5. Связанные компоненты

ConnectorService, LangflowConnectorService, ConnectionManager, BaseConnector, api/connectors, TaskService (при создании задач синхронизации).
