# Конфигурация

## 1. Что это

Настройки OpenRAG задаются переменными окружения (.env) и при необходимости конфигурационными файлами. Docker Compose передаёт переменные в контейнеры Backend и Langflow; Backend читает их через os.getenv и config_manager (config/settings.py, config/config_manager.py).

## 2. Зачем используется

Управление подключениями (OpenSearch, Langflow, Docling), выбором моделей (LLM, embedding), лимитами (таймауты, размер батча, воркеры), флагами (DISABLE_INGEST_WITH_LANGFLOW, delete_after_ingest) и путями данных.

## 3. Как работает

### config.yaml

- В проекте используется в основном конфиг из переменных окружения и config_manager (get_openrag_config). Файл config.yaml может использоваться для хранения настроек агента/провайдеров (config_manager); приоритет и источник (env vs file) задаётся в config_manager.

### Environment variables

- **OpenSearch**: OPENSEARCH_HOST, OPENSEARCH_PORT, OPENSEARCH_USERNAME, OPENSEARCH_PASSWORD, OPENSEARCH_INDEX_NAME, OPENSEARCH_DATA_PATH.
- **Langflow**: LANGFLOW_URL, LANGFLOW_PUBLIC_URL, LANGFLOW_CHAT_FLOW_ID, LANGFLOW_INGEST_FLOW_ID, LANGFLOW_URL_INGEST_FLOW_ID, NUDGES_FLOW_ID, LANGFLOW_AUTO_LOGIN, LANGFLOW_SUPERUSER, LANGFLOW_SUPERUSER_PASSWORD, LANGFLOW_KEY, LANGFLOW_TIMEOUT, LANGFLOW_CONNECT_TIMEOUT, LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT (в контейнере Langflow).
- **Docling**: DOCLING_SERVE_URL, DOCLING_OCR_ENGINE.
- **Ingestion**: DISABLE_INGEST_WITH_LANGFLOW, INGESTION_TIMEOUT, UPLOAD_BATCH_SIZE, DEFAULT_DOCS_INGEST_SOURCE, DEFAULT_DOCS_URL, DEFAULT_DOCS_CRAWL_DEPTH.
- **Embedding/LLM**: в config через knowledge.embedding_model, knowledge.embedding_provider, agent.llm_provider, agent.llm_model; провайдерские ключи: OPENAI_API_KEY, ANTHROPIC_API_KEY, WATSONX_*, OLLAMA_BASE_URL и т.д.
- **Прочее**: SESSION_SECRET, LOG_LEVEL, MAX_WORKERS, WEBHOOK_BASE_URL.

### docker compose

- docker-compose.yml задаёт сервисы: opensearch, dashboards, openrag-backend, langflow, frontend. Backend получает OPENSEARCH_*, LANGFLOW_*, INGESTION_TIMEOUT, UPLOAD_BATCH_SIZE и др. из .env. Langflow контейнер получает OPENSEARCH_URL, OPENSEARCH_PASSWORD, OPENSEARCH_INDEX_NAME и список LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT для подхвата глобальных переменных из окружения.

## 4. Где используется в системе

- config/settings.py — чтение переменных, INDEX_BODY, константы размерностей эмбеддингов, get_index_name, get_embedding_model, get_openrag_config.
- config/config_manager.py — загрузка настроек агента и провайдеров.
- main.py — инициализация клиентов и сервисов с учётом настроек.
- .env.example — шаблон переменных для развёртывания.

## 5. Связанные компоненты

config/settings, config/config_manager, main.py, docker-compose.yml, .env.
